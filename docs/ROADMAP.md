# Roadmap

## Recruiter demo implemented

- Free local semantic search over five synthetic runbooks
- Complete verbatim procedures with source references
- Session outcomes: tried, worked, did not work; skip attempted procedures
- Clarification, reported resolution, source escalation and New issue reset
- 60 draft labelled cases with family-separated calibration/held-out partitions
- Keyword, semantic and hybrid comparisons with per-case reports and failures
- Calibration-selected semantic top-k 1 / threshold 0.7
- API, workflow, persistent retrieval and headless Streamlit checks
- Actual cached-model API smoke transcript and recruiter demo walkthrough
- Blank independent review and timed-study forms, with study summarizer

## Requires human evidence

- Independent review of runbook accuracy and dataset labels
- Fresh independently authored unseen evaluation cases
- Timed next-step identification study against manual runbook lookup
- Real-world applicability and incident-resolution measurement

## Later internal helpdesk version

- Authenticated user identity and verified supervisory relationships
- Explicit access rules for creator, authorized senior and manager
- Production logging/redaction, audited access and deployment hardening
- Durable storage only when a concrete retention requirement exists
- Optional paid generation after explicit approval and budget decision
